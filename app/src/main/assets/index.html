Audio Desk checks trusted publishers for new RSS/Atom feeds every seven days while connected. Only verified feeds are added.

POST PRODUCTION RADAR is a dedicated stream for film/TV audio post, dialogue editing, ADR, Foley, sound effects, Dolby Atmos, ADM/BWF, spatial audio, Ambisonics, surround plugins, post-production DAWs, restoration, loudness, QC and delivery. It uses multiple topic-specific news searches. Plugin releases uses multiple global news searches in addition to KVR. It cannot guarantee every independent developer announcement, especially social-only posts. The Videos tab collects recent YouTube-related results via a live video-focused RSS search. Feeds are fetched through RSS2JSON. GitHub repository discovery uses GitHub's public API. Some forums and publishers restrict automated feeds, so this is a broad discovery feed rather than a guarantee of every post.
