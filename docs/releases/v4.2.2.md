# Audio Desk v4.2.2 — News feed reliability

**Sideloaded Android test release**, signed with the project's existing stable debug key. This does not replace a Play Store production release.

### Confirmed defects corrected
1. **News searches could stay disabled or show stale results.** Google/Bing RSS searches had no request deadline. They now abort after 9 seconds, always restore the Search button, ignore superseded results and avoid mixing the original bookmark link/key when the same headline appears in both engines.
2. **Removed RSS publishers could reappear after refreshing.** A response from a source removed while refresh was running could still be merged back into the news list. Refreshes now snapshot their sources, discard removed responses, remove local cache entries immediately and queue one follow-up when settings change during loading. Saved bookmarks remain.
3. **Repeated syndicated headlines.** The ordinary feed previously deduplicated primarily by URL. It now considers canonical URLs and distinctive repeated titles (at least 24 normalized characters), retains the newest 500 headlines and prevents stale GitHub discoveries from overriding later refreshes.
4. **High network pressure.** The loader formerly started a request for every publisher simultaneously, and timed-out requests continued downloading in the background. It now limits concurrent RSS requests to 12 and cancels timed-out network operations.
5. **Refresh spinner could finish too soon.** The Android refresh failsafe was 15 seconds, insufficient for slower batched feeds. The failsafe is now 60 seconds while the JavaScript flow retains balanced started/finished notifications.

### Regression tests
A new automated news-feed reliability test covers source removal in mid-request, queued refreshes, persistent cache integrity, deduplication, a 12-request concurrency ceiling, abortable network requests, cross-engine search merging, and native refresh callbacks. All existing offline, bookmarking, category, discovery, sample, launcher and wallpaper tests remain part of the full workflow.

### Remaining limitations
- External publisher RSS feeds, Google/Bing indexing, GitHub rate limits and the third-party RSS2JSON conversion service can become unreachable or impose restrictions; these are not controlled by Audio Desk.
- The app displays cached headlines offline but cannot guarantee that publisher URLs are current or that each source provides an accessible full article.
- No physical Galaxy A73 network, battery or accessibility benchmark has yet been run for this news-feed update. Test screenshots are browser simulations.
- This release does **not** change the Galaxy A73 Orbit theme or icon-pack choices.

See the successful GitHub Actions build for the precise regression and APK packaging results.
