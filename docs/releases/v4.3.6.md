# Audio Desk 4.3.6 — stability candidate

Retains the existing hybrid architecture, signing identity, production designs and all existing features. No native rewrite or new feature scope.

Fixes invalid cached workspace records, pauses workspace session UI timers and temporary reference playback when backgrounded, explicitly releases local audio when changing views, coordinates workspace overlay with refresh gestures, native RemoteViews and YouTube overlays, suspends hidden spectrum/microphone work, clears stale app-hold state on lifecycle transitions, and stops spectrum polling when disabled. Regression test covers multi-word search, malformed storage recovery, overlay/native-widget visibility, and refresh gating. Android hardware and live-service acceptance remain required; automated CI is not physical-device verification.

Also fixes the existing local reference audio file selection on Android: the trusted workspace requests audio documents, while wallpaper selection remains image-only and file:// results are still rejected. Added Android chooser regression coverage.
