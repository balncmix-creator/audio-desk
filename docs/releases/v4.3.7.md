# Audio Desk 4.3.7 — native app menu redesign

Approved compact native dialog replaces the generic Android list. Real app icon and title, theme-derived panel and accent, contrast-checked text and destructive action, native vector line icons, 48dp touch targets, cancel/back/outside dismissal and small native animation. App info, Clear cache, Force stop, Uninstall preserve existing Android-owned actions. The WebView only passes the current palette; the popup itself is native. No blur added to avoid unnecessary GPU cost. Same app ID and signing configuration. Tests exercise all native actions, cancellation, malformed palette and contrast, and styled bridge. Actual Samsung device visual acceptance remains pending.
