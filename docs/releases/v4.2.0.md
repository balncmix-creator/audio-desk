# Audio Desk Launcher v4.2.0 — QA test prerelease

**Android APK for sideloading — not a Play Store release.** Built using the repository's documented stable debug signing key. It is a development/test release, not a certified production build.

### What's new since v4.1
- **Orbit Home:** concentric radial clock, Android app-widget ring, built-in audio/news/calendar/file widgets, recent-app shortcuts and A–Z picker. Radial ends, sector seams, navigation pointer and bottom-edge controls have been visually refined.
- **Wallpaper matching:** automatic color extraction from the selected photo or wallpaper crop, including warm neutral palettes. Optional wallpaper texture shows through Orbit's surfaces while keeping readable labels.
- **Icon Studio:** 20 offline, on-device-generated app icon looks, plus original icons and simple outline; independent preferences per launcher theme. These are generated styles, not 20 imported commercial artist icon packs.
- **Orbit Files:** files, folders and actions arranged as real radial segments. The sideload/debug edition can request optional Android All files access for ordinary shared storage (Music, Downloads, Documents, Pictures and DCIM); the folder picker stays available. Android/data, Android/obb, system and other apps' protected data remain inaccessible.
- **Audio and productivity:** optional real-spectrum capture, media controls, agenda, native Android app widgets, YouTube website widget, and additional customization controls. Some depend on Android grants or external services.
- **Visual fixes:** reduce icon/fallback overlap, improve radial file-picker contrast, correct Android JavaScript bridge calls, preserve screen-edge rounding and keep neighbouring-widget controls inside their sectors.
- **Packaging regression fix:** radial file-manager JavaScript and CSS are now included in the Play-edition asset generation and the full-app browser test loader.

### Verification
- Automated UI/interaction tests, wallpaper/asset tests, Android native unit tests, debug APK build and APK packaging verification.
- Multi-screen visual review in Chromium using mock apps and representative data for five launcher themes on four phone-sized viewports. The workflow publishes the screenshots and review report as a QA artifact.
- See the GitHub Actions build associated with this release for the actual results; a green build is required before publication.

See the [detailed v4.2.0 visual and bug audit](../qa/v4.2.0.md) for coverage, corrected defects and limitations.

### What has *not* been verified
- Full visual, touch, performance, storage-provider and media-capture behavior on a physical Samsung phone with Android 16. Chromium screenshots are simulations, **not** physical-device proof.
- Some YouTube/Google account login flows may reject embedded WebView authentication; the widget shows the official site, not a guaranteed native personalized API feed.
- Some Android media providers, wallpapers and installed applications impose their own restrictions.
- Direct file-manager access still cannot override Android's protected/private directories.
- Not approved for the Play Store. A separately signed production release would require the Play-release workflow and additional review.

**Security note:** the test APK is granted only the permissions you approve. The broad shared-storage permission is declared in the debug edition only and is optional.
