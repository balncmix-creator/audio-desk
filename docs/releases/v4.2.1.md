# Audio Desk Launcher v4.2.1 — Galaxy A73 Orbit optimization

**Android sideload/test prerelease**, built with the project's stable debug signing key; not a production-signed Play Store release.

### Optimized for Samsung Galaxy A73 5G (SM-A736 family)
- **One UI navigation clearance:** Orbit's bottom-right radial dial now respects the actual Android system-bar inset reported by WindowInsets. Controls remain above the gesture-navigation area instead of disappearing beneath it.
- **Display zoom and landscape:** Layout still follows live viewport and Android insets instead of hard-coded physical pixels. The A73's 6.7-inch FHD+ portrait display, rotated screen and larger UI scaling are regression tested.
- **Touch and animation:** High-frequency radial pointer events are grouped into animation frames, and inertial animation updates are capped at about 60 redraws/second on the A73's 120Hz display to reduce unnecessary SVG rebuilding.
- **Battery/GPU:** Reduced costly background blurs during radial dragging, restored the effect on release, and stop spin/fan animations when the app is hidden.
- **Accessibility:** Orbit's Settings gear is at least 48×48 CSS pixels with explicit status-bar clearance.
- **Privacy:** The native WebView passes only a fixed `galaxy-a73`/ `generic` rendering profile. The theme does not collect or transmit model identifiers.
- **Other phones:** Existing generic responsive layout is preserved; A73 adjustments are applied only to a Samsung SM-A736-series device or equivalent internal A73 device name.

### Verification
GitHub CI runs all existing launcher and Android tests, new native device-profile tests, and an A73-emulated visual/touch test that covers 393×873 portrait, 360px display zoom, landscape, 24px gesture-navigation inset, and rapid pointer bursts. Two A73-style screenshots are included in the visual QA artifact. These screenshots use Chromium with simulated device settings and sample apps.

### Limitations
The build has **not** been installed or benchmarked on your physical Samsung Galaxy A73. Actual One UI font scaling, device temperature, live widgets, haptics, Android version, storage grants, and battery consumption still need on-device verification. A nominal 60fps redraw ceiling is a performance strategy, **not a measured guarantee**. All other permissions and app features are unchanged from v4.2.0.
