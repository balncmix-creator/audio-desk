## Artwork and memory

Each original is 1024 x 1536 pixels at the image generator's native resolution.
All sixteen are stored in lossless WebP with every original pixel preserved: no atlas,
no downsampling, no enlarged sprite, and no artificially inflated dimensions.
Each chosen image decodes to about 6 MiB; only that full-size image is resident.
The gallery uses separate 180 x 400 WebP thumbnails. Portraits fill phone screens
with reviewed cover-crop anchors that keep focal subjects visible and continue behind the status
bar. Quiet center-left space supports clock and app labels; all bundled designs use white labels on dark backgrounds. Source/output hashes, dimensions and exact fidelity are recorded
in app/src/main/assets/wallpapers/provenance.json.

## Personalization

- Ten clock designs share their exact style with the chooser; fonts are bundled
  locally, and large clocks fit narrow phones.
- Five animated overlays are selectable on every wallpaper: rain, aurora, stars,
  ocean and studio lights. They pause off Home, when the Activity pauses, and in
  reduced-motion mode; low-end devices use stepped effects.
- The system photo picker imports JPEG, PNG and WebP without broad storage access.
  A bounded WebP Blob and horizontal crop position persist locally in IndexedDB.
- Short transitions cover pages, search, sheets, menus, taps, clock changes and
  wallpaper changes. Reduced-motion preferences are respected.

## Verification

Run `npm test` for regression, interaction, actual-asset and phone-layout checks.
The asset checks require complete native generated resolution, lossless fidelity,
unique source hashes, independent thumbnails and the average 1.6 MB per wallpaper pack budget.
Actual-artwork tests exercise 16:9, 20:9 and tall phone viewports. The APK/AAB verifier
checks that every wallpaper, thumbnail, font and personalization file is packaged
unchanged. Android photo-picker tests, unit tests and builds run in GitHub Actions.
Physical-phone appearance and perceived motion have not been verified here.

## Reproduce the assets

The built-in image-generation prompts are in wallpaper-generation-prompts.json.
Original PNGs are preserved in the deliverable wallpaper ZIP. To re-import those:

```text
python scripts/import-wallpapers.py PATH_TO_ORIGINAL_PNGS --generated
npm test
```

The `--generated` policy requires at least 1024 x 1536 and unresized lossless output.
Recovered external originals retain the separate 1080 x 1920 minimum. Tiny atlases
and thumbnail sources are rejected under both policies.
