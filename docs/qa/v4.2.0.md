## Confirmed defects addressed

1. **P1 — Missing file-manager assets in production packaging and tests.** The Play-asset generation and shared browser fixture excluded `radial-files.js` and `radial-files.css`; the full launcher could therefore be tested without loading Orbit Files. Added both files to both pipelines and asserted live integration in the visual capture.
2. **P1 — Icon Studio mode cards unreadable at phone widths.** Three narrow columns plus theme-specific font caused descriptions to wrap vertically and break into tiny text fragments. Added two-column readable cards, a single column for narrow phones, larger typography and consistent settings-sheet padding. Added width/font regressions.
3. **P1 — Warm app-list icon fallback almost invisible.** Light outline artwork was drawn on a light cream tile and looked blank until native icon generation finished. Added a high-contrast dark fallback stroke for Warm and a measured contrast regression.
4. **Existing device-feedback regressions carried forward:** Orbit's app icon fallback layering, Android file-picker bridge calls, color sampling from wallpapers, clipped radial end caps, widget sector seams and bottom-edge preview symbols were corrected on their feature branches and are included here.

## Functional and packaging gates

- Existing browser tests cover Home/Apps navigation, theme switching, gestures, widget moving/resizing, wallpaper selection, color extraction, 20 icon styles, native SVG fallback handling, music visualizer state, agenda, feed content, search and radial files.
- Android native unit tests run with Robolectric; compilation produces a **stable-debug-key signed** installer. APK and separate Play-review bundle are checked before publication.
- Optional Android **All files access** is declared in the sideload/debug manifest only. It does not grant access to Android's protected other-app folders.
- The `main` workflow may create the **v4.2.0 prerelease** only if all its preceding tests and verification steps pass.

## Not yet verified / release caveats

- Real Samsung/Android 16 visual appearance, touch targets, status/navigation insets and OEM accessibility/font scaling. Chromium uses representative layouts, not a physical screen capture.
- Camera/app icon availability across all installed third-party apps, widget provider quirks and Android Storage Access Framework permissions on varied manufacturers.
- Personalized YouTube account sign-in and inline WebView restrictions, external media session permissions, playback capture, long-run power use and low-end hardware performance.
- Store publishing: the unsigned Play-review bundle is **not** a signed, approved Play Store upload.

**Release classification:** **pre-release Android test APK**. Device-specific issues should remain open and be reproduced and retested, rather than claiming universal QA completion.
